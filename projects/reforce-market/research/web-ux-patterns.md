# Веб-паттерны для Маркета Reforce

> Источник: конкурентный анализ (`projects/reforce/research/competitive-analysis.md`),  
> публичные UX-паттерны в категориях: квиз-подбор, landing-style карточки, форма заявки

---

## 1. Квиз-подбор (конфигуратор → результат)

### Лучшие практики

**Прогресс и предсказуемость**
- Показывать сколько шагов всего и на каком сейчас («Шаг 2 из 3»)
- Каждый шаг задаёт один вопрос, не список
- Автопереход на следующий шаг после выбора (без кнопки «Далее») — снижает трение

**Результаты**
- Максимум 3 варианта — иначе парадокс выбора
- Рекомендованный вариант помечен визуально и размещён в центре
- Показывать цену на карточке результата, не скрывать за «узнать»
- Кнопки «Подробнее» и «Оформить» — обе видны без скролла

**Именование пакетов**
- Имена должны описывать задачу клиента, не уровень продукта
  - «Базовый / Расширенный / Премиум» — не говорит что внутри
  - «Охрана квартиры / Охрана + видео / Охрана + умный дом»

### Антипаттерны
- Два пакета с одинаковым названием
- Квиз без отдельного URL (нельзя поделиться результатом)
- Слишком много уточняющих вопросов (>4 шага)

## 2. Landing-style карточка товара

### Структура конвертирующей страницы (сверху вниз)

```
1. Hero: название + цена + ключевые выгоды (3-4) + CTA
2. Что входит: оборудование + фото
3. Что вы получите: выгоды, не характеристики
4. Как это работает: путь клиента после заявки
5. Сравнение с другими пакетами
6. Социальное доказательство: отзывы + цифры
7. FAQ: 5-7 вопросов, снимающих возражения
8. Повтор CTA + обратный звонок
```

**Sticky CTA**
- Кнопка «Оформить» фиксируется при скролле вниз
- На мобайле: fixed bottom bar с ценой + кнопкой
- Исчезает только когда форма заявки видна на экране

**Ценообразование**
- Показывать оба числа сразу: «800 ₽/мес + оборудование 12 500 ₽»
- Добавить контекст: «Всё включено: установка + первый месяц мониторинга»
- Опционально: калькулятор срока окупаемости

### Антипаттерны
- Слишком длинная страница без sticky-CTA
- CTA только внизу страницы
- Конфигуратор оборудования с +/- (перегружает B2C-клиента)

## 3. Форма заявки

### Принципы сокращения отказов

**Прогресс-индикатор**
- Показывать шаги: «3 из 6 — Контактные данные»
- Не показывать все поля сразу — один шаг = один экран

**Автозаполнение**
- Подтянуть данные из профиля: имя, телефон
- Адрес через геолокацию браузера с возможностью уточнить

**Сохранение прогресса**
- Черновик в localStorage — если закрыл и вернулся, данные сохранены
- Предупреждение при попытке уйти со страницы без сохранения

**Финальный шаг**
- Дать выбор: самостоятельно (оплата) или через менеджера (звонок)
- Для менеджера — показать ожидаемое время звонка

### Антипаттерны
- Длинная форма без разбивки на шаги
- Обязательные поля без объяснения зачем они нужны
- Нет сохранения прогресса

## 4. Конверсионные элементы (из анализа конкурентов)

### Что работает в охранном сегменте РФ

| Элемент | Почему работает | Источник |
|---|---|---|
| Цена «от X ₽/мес» на первом экране | Устраняет барьер «сколько стоит» до изучения | Гольфстрим, Дельта |
| «Бесплатный выезд и монтаж» как первый аргумент | Главное возражение — скрытые расходы | Все конкуренты |
| Гарантия реагирования «за 5-7 минут» | Конкретика снимает недоверие | Reforce (текущий сайт) |
| Отзывы с именем + городом | Локальная релевантность | Гольфстрим |
| Онлайн-регистрация без офиса | Уникальное УТП Reforce — подчеркнуть | Gap у всех конкурентов |
| Кнопка «Заказать звонок» в хедере | Альтернативный путь для тех, кто не хочет форму | Все конкуренты |

### Gap-возможности для Reforce Маркет

| Возможность | Статус у конкурентов |
|---|---|
| 100% онлайн-оформление без визита в офис | Никто не реализовал полностью |
| Выбор объекта из ЛК при повторной заявке | Никто |
| Прозрачная разбивка цены (абонплата + оборудование) | Конкуренты скрывают стоимость оборудования |
| QR-код → скачать приложение сразу после заявки | Есть в футере у Reforce, нет в постконверсионном экране |
