**User flows:** `projects/reforce/ia/user-flows.md`

## Приоритеты (Must / Should / Could)

- **Must** — без этого продукт не работает (Этап 1)
- **Should** — важно, но можно во 2 итерации
- **Could** — желательно, если есть ресурс

---

## 1. Авторизация (UF-AUTH)

| Требование | Приоритет |
|---|---|
| Вход по номеру телефона + SMS-код (OIDC) | Must |
| Биометрический вход: Face ID / Touch ID после первичной авторизации | Must |
| PIN-пад (не текстовое поле) как резервный метод — минимум 4 цифры | Must |
| Регистрация нового пользователя | Must |
| Миграция существующих пользователей из старого ЛК (1С → OIDC) | Must |
| Автологин при активной сессии + биометрия | Should |
| Восстановление доступа через поддержку | Should |

---

## 2. Главная — список объектов (UF-MAIN)

| Требование | Приоритет |
|---|---|
| Список объектов с мгновенным статусом | Must |
| Статус = цвет + иконка + текст (тройное кодирование) | Must |
| Переход в карточку объекта в 1 тап | Must |
| Кэш последнего статуса при отсутствии связи + индикатор offline | Must |
| Поиск по названию объекта | Should |
| Фильтр / сортировка по статусу | Should |

---

## 3. Карточка объекта

| Требование | Приоритет |
|---|---|
| Статус охраны виден без скролла, крупно | Must |
| Системные индикаторы (питание, связь, батарея) с пояснением состояния и CTA при проблеме | Must |
| Разделы объекта со статусом каждого | Must |
| Вкладки «Информация / События» | Must |
| Переход в настройки объекта | Must |

---

## 4. Постановка / Снятие (UF-ARM)

| Требование | Приоритет |
|---|---|
| Постановка всего объекта: нажатие → PIN-пад → подтверждение | Must |
| Снятие всего объекта: нажатие → PIN-пад → подтверждение | Must |
| Раздельное управление разделами | Must |
| Визуальный + тактильный (haptic) фидбек на смену статуса | Must |
| Ответ Securige API ≤ 2 сек | Must |
| Ошибка API: понятный текст + кнопка «Повторить» | Must |
| Offline: поставить в очередь и выполнить при восстановлении связи | Should |

---

## 5. Тревожная кнопка / ГБР / КТС (UF-GBR, UF-KTS)

| Требование | Приоритет |
|---|---|
| Вызов ГБР: защита от случайного нажатия (long press или экран подтверждения) | Must |
| Статус выезда ГБР + ETA в реальном времени | Must |
| Push при подтверждённом инциденте: пробивает «Не беспокоить» (APNs Critical Alerts / Android HIGH_PRIORITY) | Must |
| Заглушка «ГБР не подключена» + CTA «Подключить услугу» | Must |
| КТС-тест: проверка работоспособности тревожной кнопки | Must |
| Фото-верификация в push при тревоге | Should |
| Отчёт ГБР с фото после выезда | Should |
| Оценка качества выезда (1-5 звёзд) | Should |

---

## 6. Лента событий (UF-INC)

| Требование | Приоритет |
|---|---|
| Хронологическая лента с группировкой по дате | Must |
| Человекочитаемый язык: «Свет отключился → резервное питание включилось» | Must |
| Иконка + цвет для каждого типа события | Must |
| Push только при реальном выезде ГБР — не при каждом срабатывании датчика | Must |
| Фильтр по типу события | Should |
| Детали события: что произошло, кто поставил/снял, статус обработки | Should |

---

## 7. Управление доступами (UF-ACCESS)

| Требование | Приоритет |
|---|---|
| Список пользователей с ролью каждого | Must |
| Приглашение нового пользователя по номеру телефона | Must |
| Выбор роли при приглашении | Must |
| Удаление пользователя с подтверждением | Must |
| Экран принятия приглашения для нового пользователя | Must |
| Изменение роли существующего пользователя | Should |

---

## 8. Платежи (UF-PAY)

| Требование | Приоритет |
|---|---|
| Список договоров с балансом (нейтральный стиль, не красный при отрицательном) | Must |
| Детали договора: баланс, абонплата, история операций | Must |
| Онлайн-оплата (СБП, карта) | Must |
| Уведомление о предстоящем списании (за 3-5 дней) | Must |
| Список подключённых объектов к договору | Should |
| Автоплатёж | Should |
| Электронные счета и акты | Should |

---

## 9. Поддержка

| Требование | Приоритет |
|---|---|
| Чат со специалистом | Must |
| Контактные данные и реквизиты | Must |
| История обращений | Should |
| Онбординг / обучение по приложению | Should |

## 10. Профиль

| Требование | Приоритет |
|---|---|
| ФИО, телефон, email | Must |
| Управление биометрией и PIN | Must |
| Настройки уведомлений: 3 категории (критические / важные / информационные) | Must |
| Выход из аккаунта | Must |

---

## 11. Интеграции

| Система | Назначение | Статус |
|---|---|---|
| Securige API | Постановка/снятие, статусы, события, ГБР | Блокер: контракт не подписан |
| OIDC | Единая авторизация ЛК + Маркет | В работе |
| APNs Critical Alerts | Push iOS, пробивает DND | Требует реализации |
| FCM / RuStore | Push Android (RuStore — приоритет для РФ) | Требует реализации |
| Платёжный шлюз | Онлайн-оплата, СБП | Не выбран |
| Чат-платформа | Поддержка 24/7 | Не выбрана |
