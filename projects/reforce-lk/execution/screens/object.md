# OBJ — Карточка объекта

Детальная страница конкретного объекта. Статус виден без скролла.

**Экраны:**
- Под охраной — статус крупно, системные индикаторы ОК, кнопка «Снять»
- Снят с охраны — кнопка «Поставить», вкладки «Информация / События»
- Тревога (активный инцидент) — красный статус, анимация, кнопка ГБР активна
- Проблема с индикатором — батарея / питание / связь с предупреждением + CTA «Что делать?»
- Разделы объекта — список зон с индивидуальным статусом каждой
- Вкладка «Информация» — адрес, тариф, устройства, ответственные

**Ключевые решения (из аудита):** серые иконки заменить на статусные; системные индикаторы — с объяснением, не просто красный восклицательный знак.
