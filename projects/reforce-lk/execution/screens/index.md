## Очерёдность разработки

1. **MAIN-01, MAIN-02** — без главной экрана нет приложения
2. **OBJ-01, OBJ-02** — карточка объекта + ARM-01..05 (ключевой flow)
3. **GBR-01..03** — ГБР (высокий приоритет по PRD)
4. **INC-01, INC-03** — лента + детали инцидента
5. **ACCESS-01..04** — доступы
6. **PROFILE-01..03** — профиль
7. **KTS, SUPPORT** — последними
