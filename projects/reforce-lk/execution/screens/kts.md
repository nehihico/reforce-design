# KTS — Проверка тревожной кнопки (КТС-тест)

Проверка работоспособности оборудования. Инициируется пользователем.

**Экраны:**
- Подтверждение — «Сейчас отправим тестовый сигнал на пульт» + «Начать проверку»
- Тест в процессе — индикатор ожидания ответа
- Успешно — «Кнопка исправна» (зелёная галочка)
- Ошибка — «Сигнал не получен» + «Обратиться в поддержку»
