# GBR — Вызов ГБР / Тревожная кнопка

Экстренный сценарий. Защита от случайного нажатия обязательна.

**Экраны:**
- Подтверждение вызова — long-press или модал «Вызвать группу реагирования?»
- Вызов отправлен — «Направили группу реагирования» + индикатор ожидания
- Статус в пути — таймлайн: диспетчер принял → группа выехала → ETA 12 мин
- ГБР прибыла — «Группа реагирования на месте»
- Отчёт с фото — текст итогов + фотографии с объекта + оценка 1–5 звёзд
- ГБР не подключена — заглушка «Услуга не подключена» + CTA «Подключить в магазине»

**Ключевые решения (из аудита):** убрать большую розовую карточку без защиты (C2). Кнопка вызова — только внутри объекта, не в общем скролле.
