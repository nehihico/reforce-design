# AUTH-MIGRATE — Миграция из старого ЛК

Один раз — при первом открытии обновлённого приложения пользователем старой версии.

**Экраны:**
- «Мы обновили систему входа» — объяснение, что происходит, без паники
- Ввод телефона (тот же что был в старом ЛК)
- Подтверждение SMS
- Привязка объектов и истории — прогресс
- Успешная миграция → «Добро пожаловать в новый Reforce»
- Ошибка: номер не найден → «Обратитесь в поддержку»
