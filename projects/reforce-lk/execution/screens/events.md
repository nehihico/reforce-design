# INC — Лента событий и детали инцидента

История всего, что происходило на объекте. Человекочитаемый язык обязателен.

**Экраны:**
- Лента событий — хронологический список, группировка по дате
- Лента — фильтр по типу (постановка/снятие / инциденты / система)
- Детали события (инцидент + ГБР) — таймлайн: движение → оператор верифицировал → ГБР выехала → прибыла
- Детали события (системное) — «Свет отключился → резервное питание включилось» с объяснением причины
- Push на экране блокировки — мок уведомления: «Движение в зоне Гостиная» + быстрые кнопки

**Ключевые решения (из аудита):** заменить технические коды (C3, C4) на человекочитаемый язык; иконки с типом для каждого события.
