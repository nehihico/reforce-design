# AUTH-PIN — PIN-пад и биометрия

Резервный и быстрый вход для возвращающихся пользователей.

**Экраны:**
- PIN-пад (4 цифры, нативные круглые клавиши, haptic на каждую)
- Биометрия — запрос Face ID / Touch ID при открытии приложения
- Ошибка PIN (неверный код, осталось N попыток)
- Сброс PIN через поддержку (после исчерпания попыток)

**Логика:** после первичного входа по SMS — следующий запуск предлагает биометрию или PIN.
