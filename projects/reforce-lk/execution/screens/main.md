# MAIN — Главная / Список объектов

Центральный экран приложения — первое, что видит пользователь после входа.

**Экраны:**
- Несколько объектов с разными статусами (под охраной / снят / тревога / требует внимания)
- Один объект — упрощённый вид, статус крупно в центре
- Нет объектов (empty state) — «Объектов пока нет» + CTA «Перейти в магазин»
- Offline-режим — кэшированные статусы + баннер «Данные могут быть устаревшими»
- Боттомшит фильтра — по статусу (все / на охране / сняты / тревога)

**Ключевые решения:** статус = тройное кодирование (цвет + иконка + текст). Один тап → карточка объекта.
