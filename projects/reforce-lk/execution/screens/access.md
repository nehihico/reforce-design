# ACCESS — Управление доступами

Делегирование прав на объект сотрудникам, членам семьи. Особо важно для Максима (малый бизнес).

**Экраны:**
- Список пользователей — имя, роль (Владелец / Пользователь), статус (Активен / Ожидает принятия)
- Приглашение — ввод номера телефона
- Выбор роли — радио с описанием прав каждой роли
- Приглашение отправлено — тост + статус «Ожидает» в списке
- Принятие приглашения (со стороны нового пользователя) — «Вас пригласили управлять объектом» + принять/отклонить
- Удаление пользователя — модал подтверждения «Удалить [Имя]? Доступ будет закрыт»

**Ключевые решения (из аудита):** добавить роли в список (S4), кнопку «Пригласить» сразу видна.
