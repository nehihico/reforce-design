# ARM — Постановка и снятие с охраны

Ключевой flow приложения. 2 раза в день для большинства пользователей.

**Экраны:**
- Постановка — PIN-пад в боттомшите (не текстовое поле)
- Снятие — аналогичный PIN-пад
- Частичная охрана — выбор разделов чекбоксами → ввод кода
- Успешная постановка — анимация статуса «Объект под охраной»
- Успешное снятие — анимация «Снят с охраны»
- Ошибка кода — shake-анимация + счётчик «Осталось 2 попытки»
- Ошибка API — «Не удалось связаться с объектом» + кнопка «Повторить»
- Offline — «Нет связи. Выполним при восстановлении соединения»
- Нет прав — заглушка «У вас нет прав для этого действия»

**Ключевые решения (из аудита):** PIN-пад вместо текстового поля (C1), haptic-фидбек на каждую цифру и на результат.
