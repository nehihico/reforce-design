# PROFILE — Профиль и настройки

Личные данные, безопасность, уведомления. Используется редко, но должен быть понятным.

**Экраны:**
- Мои данные — ФИО, телефон, email, кнопка «Редактировать»
- Безопасность — смена PIN, включить/выключить Face ID / Touch ID
- Настройки уведомлений — 3 категории тогглов: Критические (тревога, ГБР) / Важные (постановка/снятие) / Информационные (системные события)
- Выход из аккаунта — модал подтверждения
