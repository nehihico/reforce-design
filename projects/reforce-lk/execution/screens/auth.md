# AUTH — Авторизация

Сценарий входа и регистрации нового пользователя.

**Экраны:**
- Ввод номера телефона (+7, валидация формата)
- Ввод SMS-кода (6 цифр, таймер, «Отправить повторно», ошибка)
- Регистрация нового пользователя (ФИО + 2 чекбокса согласий)
- Экран успешного входа (анимация → переход на Главную)

**Демо-сценарий:** 9991234567 = уже зарегистрирован → ввод кода; любой другой → регистрация. Код 123456.

**Статус:** Утверждено
