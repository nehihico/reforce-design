# Проблемы и метрики: Личный кабинет Reforce

**Версия:** 1.0 (май 2026)  
**Источник:** PRD v3.2, аудит prod-3.4.37-88

---

## Текущие проблемы

| # | Проблема | Тип | Влияние |
|---|---|---|---|
| P1 | **Конфликт моделей пользователей** — ЛК через 1С, Магазин через OIDC. У клиента два разных аккаунта | Архитектурный блокер | Клиент не может перейти из магазина в ЛК без повторной регистрации |
| P2 | **Push-уведомления протухают** — при редком использовании приложения токен устаревает | Технический | Клиент не узнаёт о выезде ГБР — это ключевое обещание продукта |
| P3 | **Интерфейс устарел** — не соответствует позиционированию платформы (банковский UX vs охранная утилита) | UX | Отток, негативные отзывы, несоответствие бренду |
| P4 | **Нет онлайн-оплаты** — 0% цифровых платежей, всё через оператора | Продуктовый | Операционная нагрузка на поддержку, медленный опыт клиента |
| P5 | **Управление доступами через звонок** — добавить/убрать пользователя = звонок оператору, задержка часы/дни | UX + операционный | Критично для B2B (Максим, Алина) |
| P6 | **PIN вводится в текстовое поле** | UX | Непривычно, нет haptic, цифры видны на экране |
| P7 | **Тревожная кнопка без защиты от случайного нажатия** | Безопасность + UX | Риск ложных вызовов ГБР |
| P8 | **События написаны техническим языком** — «Пропущенное отключение сети 220в» | UX | Виктор (45+) не понимает что происходит и нужно ли реагировать |
| P9 | **Красный цвет используется везде** — статус, кнопки, баланс, тревога, тогглы | Дизайн | Красный теряет смысл как сигнал, растёт тревожность |
| P10 | **Нет ГБР-трекинга** — клиент не видит статус выезда и ETA | Продуктовый | Тревога и ощущение брошенности во время инцидента |

Детальный аудит текущей версии: `audit/lk-v3-current.md`
