## Что это за продукт

Мобильное приложение (Flutter, iOS + Android) — основной ежедневный интерфейс клиента платформы Reforce. Через него клиент управляет охраной, получает уведомления об инцидентах, платит за услуги и обращается в поддержку.

Это не «приложение к охранной компании» — это **охрана внутри приложения**. Клиент не звонит, не приезжает в офис, не разбирается в технике. Всё через смартфон.

## Позиционирование продукта

**Аналог:** Тинькофф — всё через приложение, без отделений и звонков.  
**Тон:** спокойная уверенная сила. Не «система охраны», а «спокойствие в кармане».  
**Визуальный стандарт:** банковские приложения РФ — чисто, без паники, цифры читаемы.  
**Запрет:** слова «тревога», «шлейф», «зона охраны», «пинкод» в интерфейсе.

## Платформа и ограничения

| Параметр | Значение |
|---|---|
| Платформа | Flutter (iOS 14+, Android 8+) |
| Push (Android) | RuStore SDK — приоритет для РФ |
| Push (iOS) | APNs Critical Alerts — пробивают режим «Не беспокоить» |
| Авторизация | OIDC — единая с Маркетом |
| Данные | 152-ФЗ, хранение в РФ |
| Tap-зоны | ≥ 44px; критичные действия ≥ 80px |
| Аудитория | Включает пожилых — Dynamic Type, высокий контраст, простой язык |
| API охраны | Securige (блокер: контракт не подписан) |
