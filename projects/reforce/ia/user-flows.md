# User Flows — Reforce

> Источник: Figma (REFORCE, 2026-05-15) + PRD v3.2  
> Платформы: мобильное приложение (Flutter), веб-ЛК, веб-магазин

---

## UF-AUTH: Авторизация

```mermaid
flowchart TD
  A[Открывает приложение] --> B[Экран: Ввод телефона]
  B --> C[Нажимает Продолжить]
  C --> D[Экран: Ввод SMS-кода]
  D --> E{Код верный?}
  E -->|Нет / истёк| F[Экран: Отправить повторно]
  F --> D
  E -->|Да| G{Пользователь существует?}
  G -->|Да — мигрирует| H[Экран миграции из старого ЛК]
  H --> MAIN[Главная]
  G -->|Да — новый OIDC| MAIN
  G -->|Нет| I[Экран: Регистрация]
  I --> MAIN
```

## UF-MAIN: Навигация по объектам

```mermaid
flowchart TD

  DETAIL --> EDIT[Редактировать объект]

  DETAIL --> ACCESS[Права доступа]
  DETAIL --> EVENTS[Лента событий]
  DETAIL --> SUPPORT_BTN[Поддержка]
```

## UF-ARM: Постановка / Снятие с охраны

```mermaid
flowchart TD
  A[Объект — текущий статус] --> B{Есть права на постановку?}
  B -->|Нет| C[Заглушка: Нет прав]
  B -->|Да| D{Действие}
  D -->|Поставить всё| E[Ввод кода]
  D -->|Частичная охрана| F[Выбор разделов → ввод кода]
  D -->|Снять| G[Ввод кода]
  E & F & G --> H{Код верный?}
  H -->|Нет| I[Ошибка — повторить]
  I --> E
  H -->|Да| J[Запрос в Securige API]
  J --> K{Ответ ≤ 2 сек}
  K -->|Успех — на охране| L[Статус: Код на защите]
  K -->|Успех — частичная| M[Статус: Код частичная]
  K -->|Успех — снят| N[Статус: Код снят]
  K -->|Ошибка API| O[Ошибка + кнопка Повторить]
  K -->|Нет связи| P[Offline: в очередь]
```

## UF-GBR: Вызов ГБР / Тревожная кнопка

```mermaid
flowchart TD
  A[Пользователь нажимает Тревога] --> B{ГБР куплена?}
  B -->|Нет| C[Заглушка: функция недоступна]
  C --> D[Кнопка: Подключить услугу]
  B -->|Да| E[Подтверждение вызова]
  E --> F[Вызов отправлен в пульт]
  F --> G[Push: Направили группу реагирования]
  G --> H[Статус выезда + ETA]
  H --> I[После выезда: отчёт с фото]
  I --> J[Оценка качества выезда]
```

## UF-INC: Инцидент → уведомление → ГБР

```mermaid
flowchart TD
  A[Датчик сработал] --> B[Событие на пульте Securige]
  B --> C[Оператор верифицирует]
  C --> D{Результат}
  D -->|Ложная тревога| E[Push НЕ отправляется]
  E --> F[Запись в ленте событий]
  D -->|Подтверждено — выезд ГБР| G[Push: Направили группу реагирования]
  G --> H[Клиент видит статус + ETA]
  H --> I[Отчёт ГБР с фото]
  I --> J[Оценка качества]
  D -->|Критическая угроза| K[Push + SMS + Звонок ответственному]
  K --> G
```

**UX-принцип:** 90%+ срабатываний — ложные. Push только при реальном выезде ГБР.

## UF-ACCESS: Управление правами доступа

```mermaid
flowchart TD
  A[Объект → Права доступа] --> B[Список пользователей]
  B --> C{Действие}
  C -->|Добавить| D[Ввод телефона нового пользователя]
  D --> E[Выбор роли]
  E --> F[Отправка приглашения]
  F --> G[Новый пользователь: экран принятия приглашения]
  G --> H{Принял?}
  H -->|Да| I[Доступ предоставлен — статус: Доступ к ЛК]
  H -->|Нет / истёк| J[Приглашение аннулировано]
  C -->|Удалить| K[Подтверждение]
  K --> L[Пользователь потерял доступ]
  C -->|Изменить роль| M[Выбор новой роли → сохранить]
```

## UF-PAY: Оплата договора

```mermaid
flowchart TD
  A[Финансы → Список договоров] --> B{Статус договора}
  B -->|Активный| C[Договор — активный]
  B -->|Неактивный| D[Договор — неактивный]
  C --> E{Сценарий оплаты}
  E -->|Плановая| F[Ближайший платёж]
  E -->|До отключения| G[Оплата до отключения услуги]
  E -->|После отключения| H[Оплата после отключения]
  F & G & H --> I[Экран оплаты]
  I --> J[Выбор способа оплаты]
  J --> K[Подтверждение]
  K --> L{Результат}
  L -->|Успех| M[Оплата — успешно]
  L -->|Ошибка| N[Ошибка → повторить]
```

## UF-SHOP: Покупка → Заявка → ЛК

```mermaid
flowchart TD
  A[Главная магазина] --> B[Определение геолокации]
  B --> B2[Карта — выбор объекта]
  A --> C[Выбор типа услуги]
  C --> D[Каталог / Сравнение пакетов]
  D --> D2[Квартира / Коттедж / Бизнес / Гараж и Дача]
  D2 --> E[Карточка товара]
  E --> E2[Поделиться ссылкой]
  E --> E3[Обратный звонок]
  E --> E4[Замена устройства]
  E --> F[Оформить заявку]

  F --> G{Авторизован?}
  G -->|Нет| H[Авторизация — телефон + код]
  H --> I
  G -->|Да| I

  I[Заполнение анкеты] --> J{Есть объект?}
  J -->|Да| J1[Выбор объекта на карте]
  J -->|Нет| J2[Ввод адреса]
  J1 & J2 --> K[Форма собственности]
  K --> L[Контактные данные]
  L --> M[Промокод — опционально]
  M --> N[Ответственные лица]
  N --> O[Прикрепление документов]
  O --> P[Согласие на обработку данных]
  P --> Q{Способ заполнения}
  Q -->|Сам| R[Оплата заказа]
  Q -->|Через менеджера| S[Менеджер перезвонит]
  R --> T[Заявка создана]

  T --> U[Раздел: Заявки]
  U --> V[Карточка заявки]
  V --> W{Анкета требует правки?}
  W -->|Да| X[Редактирование анкеты]
  X --> V
  W -->|Нет| Y{Заявка активна?}
  Y -->|Да| Z[Статус: в работе → монтаж]
  Y -->|Нет| AA[Отмена заказа]
  Z --> LK[Объект появляется в ЛК]
```

## UF-MIGRATE: Миграция из старого ЛК

```mermaid
flowchart TD
  A[Открывает обновлённое приложение] --> B[Экран: Обновление системы входа]
  B --> C[Вводит телефон]
  C --> D[SMS-код]
  D --> E{Найден в старом ЛК?}
  E -->|Да| F[Привязывает объекты и историю]
  F --> G[Переходит в обновлённый ЛК]
  E -->|Нет| H[Ручная миграция через поддержку]
  E -->|Дубликат| I[Экран сверки данных]
  I --> G
```

## UF-CANCEL: Расторжение договора

```mermaid
flowchart TD
  A[Клиент инициирует расторжение] --> B[Выбирает причину]
  B --> C{Причина}
  C -->|Недоволен качеством| D[Автоэскалация на менеджера]
  D --> E{Клиент передумал?}
  E -->|Да| F[Расторжение отменено]
  E -->|Нет| G[Период охлаждения]
  C -->|Переезжаю| H[Предложение переноса]
  H --> E
  C -->|Продал объект| I[Предложение охраны нового + реферал]
  I --> G
  C -->|Другое| G
  G --> J[Фактическое расторжение]
  J --> K[Аккаунт: неактивный]
  K --> L[Win-back: 1/3/6 мес.]
```

**Принцип:** расторжение — это процесс удержания, не кнопка удалить.
