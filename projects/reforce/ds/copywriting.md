> Эталон: Тинькофф, Яндекс (чёткость + человечность).

| Мы | Не мы |

## Принципы написания текстов

### Будь конкретным
**Плохо:** «Произошла ошибка»  
**Хорошо:** «Не удалось отправить код. Попробуйте ещё раз»

### Скажи что делать дальше
**Плохо:** «Ошибка подключения»  
**Хорошо:** «Нет подключения к интернету. Проверьте соединение и попробуйте снова»

### Говори на «ты» (или без обращения)
**Плохо:** «Вы можете поставить объект на охрану»  
**Хорошо:** «Поставьте объект на охрану» / «Объект поставлен на охрану»

### Избегай пассивного залога
**Плохо:** «Заявка была создана»  
**Хорошо:** «Заявка создана» / «Мы получили заявку»

### Без технического жаргона
**Плохо:** «Произошло срабатывание зоны ПИК-детектора»  
**Хорошо:** «Движение в зоне 2 — Гостиная»

## Кнопки и действия

### Правила для CTA-кнопок
- Глагол + объект: **«Поставить на охрану»**, не «Охрана»
- Не более 3–4 слов
- Описывает результат, а не процесс
- Первое слово с заглавной, остальные строчные

| Контекст | Хорошо | Плохо |
|---|---|---|
| Постановка | «Поставить на охрану» | «Охрана», «Активировать», «OK» |
| Снятие | «Снять с охраны» | «Деактивировать», «Отмена охраны» |
| Подтверждение | «Подтвердить», «Готово» | «OK», «Да», «Submit» |
| Отмена | «Отмена» | «Нет», «Закрыть», «Cancel» |
| Вход | «Войти» | «Логин», «Sign In», «Авторизоваться» |
| Регистрация | «Создать аккаунт» | «Зарегистрироваться», «Sign Up» |
| Сохранение | «Сохранить» | «Применить изменения», «Submit» |
| Удаление | «Удалить» | «Уничтожить», «Remove» |
| Оплата | «Оплатить» | «Совершить платёж», «Pay» |
| Далее в шагах | «Далее» | «Продолжить», «Следующий шаг» |

### Кнопки подтверждения опасных действий
Основная кнопка описывает последствие, а не просто «Да»:

**«Снять с охраны?»** → кнопка «Снять с охраны», не «Да» / «Подтвердить»  
**«Удалить объект?»** → кнопка «Удалить объект», не «Удалить»

## Заголовки экранов

- Кратко и по сути: **«Авторизация»**, не «Вход в систему личного кабинета»
- Без артиклей и лишних слов
- Описывает экран, а не действие пользователя

| Экран | Заголовок |
|---|---|
| Вход по номеру | «Вход» |
| Ввод SMS-кода | «Подтверждение» |
| Регистрация нового пользователя | «Регистрация» |
| Главный экран ЛК | «Главная» |
| Список объектов | «Объекты» |
| Детали объекта | «[Адрес объекта]» |
| История событий | «События» |
| Настройки | «Настройки» |

## Плейсхолдеры

- Описывают формат, а не повторяют лейбл
- Исчезают при вводе (не плавающий лейбл — это отдельный компонент)

| Поле | Плейсхолдер |
|---|---|
| Номер телефона | «+7 (900) 000-00-00» |
| ФИО | «Иванов Иван Иванович» |
| Email | «mail@example.com» |
| Адрес объекта | «ул. Ленина, 5, кв. 12» |
| Поиск | «Поиск по объектам» |

## Ошибки и валидация

### Структура сообщения об ошибке
1. Что пошло не так (конкретно)
2. Что делать (если неочевидно)

**Плохо:** «Ошибка 400», «Неверные данные», «Что-то пошло не так»  
**Хорошо:** «Неверный код. Осталось 2 попытки», «Такой номер уже зарегистрирован — войдите»

### Частые ошибки

| Ситуация | Текст ошибки |
|---|---|
| Неверный формат телефона | «Введите номер в формате +7 (XXX) XXX-XX-XX» |
| Неверный SMS-код | «Неверный код. Попробуйте ещё раз» |
| Исчерпаны попытки кода | «Слишком много попыток. Запросите новый код» |
| Нет интернета | «Нет соединения с интернетом» |
| Сервер недоступен | «Сервис временно недоступен. Попробуйте позже» |
| Сессия истекла | «Сессия завершена. Войдите снова» |
| Поле обязательное | «Заполните это поле» |
| Не принято соглашение | «Необходимо согласие для продолжения» |

## Пустые состояния

Структура: иконка → заголовок → подзаголовок → кнопка (если есть действие)

| Экран | Заголовок | Подзаголовок |
|---|---|---|
| Нет объектов | «Объектов пока нет» | «Добавьте первый объект для мониторинга» |
| Нет событий | «События не найдены» | «Здесь появятся уведомления об объекте» |
| Нет уведомлений | «Всё спокойно» | «Уведомления появятся при изменении статуса» |
| Нет результатов поиска | «Ничего не найдено» | «Попробуйте изменить запрос» |
| Нет подключения | «Нет соединения» | «Проверьте интернет и обновите страницу» |

## Подтверждения действий (модальные)

Структура: иконка → вопрос → описание последствий → кнопка-действие + «Отмена»

```
Снять с охраны?
Объект перестанет отслеживаться до следующей постановки.

[Снять с охраны]   [Отмена]
```

```
Удалить объект?
Это действие нельзя отменить. История событий будет удалена.

[Удалить объект]   [Отмена]
```

## Уведомления (Push и тосты)

- Кратко: факт + объект
- Без восклицательных знаков при статусных событиях
- Восклицательный знак — только для тревоги

| Событие | Текст уведомления |
|---|---|
| Постановка на охрану | «Квартира поставлена на охрану» |
| Снятие с охраны | «Квартира снята с охраны» |
| Тревога | «Тревога! Движение на объекте» |
| ГБР направлена | «ГБР направлена на объект» |
| Платёж прошёл | «Платёж принят» |
| Истекает договор | «Договор истекает через 7 дней» |
