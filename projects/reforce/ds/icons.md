# DS: Иконки — Reforce

> Библиотека: **Lucide Icons** (open-source, MIT).  
> Стиль: outline (линейный), stroke-width 1.5–2, скруглённые концы.

---

## Размерная сетка

Все иконки кратны 8px. Визуальная область (optical size) чуть меньше холста.

| Токен | Холст | Применение |
|---|---|---|
| `icon-xs` | 14px | Внутри бейджей, статус-точки заменитель |
| `icon-sm` | 16px | Inline в тексте, вторичные действия |
| `icon-md` | 20px | Стандарт в карточках, инпутах, кнопках |
| `icon-lg` | 24px | Таббар, хедер, основные элементы списка |
| `icon-xl` | 28px | Пустые состояния, онбординг-иллюстрации |
| `icon-2xl` | 32px | Hero-блоки, статус ARM |
| `icon-3xl` | 40px | Крупные статусные иконки (центр экрана) |

---

## Stroke width

| Размер иконки | Stroke |
|---|---|
| 14–16px | 2.0px |
| 20–24px | 1.5–2.0px |
| 28–40px | 1.5px |

**Правило:** чем крупнее иконка, тем тоньше stroke. На маленьком размере тонкий stroke теряется.

---

## Стиль: outline vs filled

| Состояние | Стиль |
|---|---|
| Неактивный таб | Outline (`fill="none"`, `stroke="currentColor"`) |
| Активный таб | Filled (`fill="currentColor"`) |
| Кнопка с иконкой | Outline |
| Статусная иконка (armed/alarm) | Filled для яркости |
| Декоративная иконка | Outline |

```html
<!-- Outline -->
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5"
     stroke-linecap="round" stroke-linejoin="round">

<!-- Filled -->
<svg viewBox="0 0 24 24" fill="currentColor">
```

## Цвет иконок

Иконки наследуют цвет через `currentColor`. Устанавливай цвет через класс или переменную.

| Контекст | Цвет |
|---|---|
| Активный таб | `#D42B2B` |
| Неактивный таб | `#8E8E93` |
| В карточке (нейтральная) | `#636366` |
| Статус «под охраной» | `#34C759` |
| Статус «тревога» | `#FF3B30` |
| Статус «ГБР» | `#007AFF` |
| Статус «внимание» | `#FF9500` |
| На белой кнопке (ghost) | `#D42B2B` |
| На красной кнопке (primary) | `#FFFFFF` |
| Disabled | `#C7C7CC` |

## Использование в HTML/Tailwind

```html
<!-- Иконка в кнопке -->
<button class="flex items-center gap-2">
  <svg class="size-5 shrink-0" viewBox="0 0 24 24" fill="none"
       stroke="currentColor" stroke-width="1.5"
       stroke-linecap="round" stroke-linejoin="round">
    <!-- path -->
  </svg>
  Поставить на охрану
</button>

<!-- Иконка статуса (filled) -->
<svg class="size-6 text-[#34C759]" viewBox="0 0 24 24" fill="currentColor">
  <!-- path -->
</svg>

<!-- Спиннер загрузки -->
<svg class="size-5 animate-spin text-[#D42B2B]" viewBox="0 0 24 24" fill="none"
     stroke="currentColor" stroke-width="2">
  <path d="M21 12a9 9 0 11-6.22-8.56" stroke-linecap="round"/>
</svg>
```

## Недопустимо

| Запрет | Причина |
|---|---|
| Иконки с образами охранников, форм, камер видеонаблюдения как бренд-образ | Противоречит позиционированию «не охранная компания» |
| Смешивать outline и filled без логики (состояния) | Нарушает консистентность |
| Использовать иконку без текстовой подписи для критических действий | Нарушает a11y, особенно для пожилых |
| Менять stroke-width произвольно | Разрушает единство стиля |
