## Правила компоновки

### Иерархия плотности

```
Плотный список (события, транзакции)  →  gap: 0, border-bottom
Стандартный список (объекты)          →  gap: 8px
Карточная сетка                       →  gap: 12–16px
Секции страницы                       →  gap: 24–32px
```

### Выравнивание иконок с текстом

- Иконка 16px → вертикальное центрирование с первой строкой текста (`items-center` для однострочных, `items-start mt-0.5` для многострочных)
- Иконка 20px+ → всегда `items-center`

### Safe-areas на мобиле

Все фиксированные элементы снизу обязаны учитывать `env(safe-area-inset-bottom)`:
```html
<div class="pb-[env(safe-area-inset-bottom)]">...</div>
```

Контентные области должны добавлять отступ снизу под таббар:
```html
<div class="pb-[calc(49px+env(safe-area-inset-bottom)+16px)]">...</div>
```

## 8px-чеклист

Перед сдачей экрана проверь:
- [ ] Все отступы кратны 4px (предпочтительно 8px)
- [ ] Нет «магических» чисел типа 13px, 15px, 7px
- [ ] Горизонтальные поля контента = 16px (мобайл)
- [ ] Высоты интерактивных элементов ≥ 44px
- [ ] Фиксированные элементы учитывают safe-area
