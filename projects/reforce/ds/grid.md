# DS: Сетка и компоновка — Reforce

> Базовая единица: **8px**. Все отступы и размеры кратны 8 (кроме xs=4px).  
> Три платформы: **[MOB]** Mobile · **[WEB]** Web 1440 · **[DSK]** Desktop 1920

---

## Платформы и продукты

| Маркер | Размер | Продукт | Устройство |
|---|---|---|---|
| `[MOB]` | 390×844px | reforce-lk | iPhone (base), Android |
| `[WEB]` | 1440×1024px | reforce-market, веб-ЛК | Ноутбук, планшет ландшафт |
| `[DSK]` | 1920×1080px | reforce-market, панель управления | Широкий монитор |

## [MOB] Мобильная сетка (reforce-lk)

### Канвас
| Параметр | Значение |
|---|---|
| Ширина рабочей области | 390px (iPhone 14 base) |
| Высота | 844px |
| Статус-бар (iOS) | 54px |
| Безопасная зона сверху | `env(safe-area-inset-top)` |
| Навбар / хедер | 44px |
| Таббар | 49px |
| Безопасная зона снизу | `env(safe-area-inset-bottom)` |

### Колонки
4 колонки, гутер 16px, поля 16px с каждой стороны.

```
|16px| col | 16px | col | 16px | col | 16px | col |16px|
```

### Горизонтальные отступы

| Зона | Padding |
|---|---|
| Контент страницы | `px-4` = 16px |
| Хедер | `px-4` = 16px |
| Полноширинные кнопки (CTA) | `px-4` = 16px от краёв |
| Контент внутри карточки | `p-4` = 16px |

### Вертикальный ритм

| Переход | Отступ |
|---|---|
| После хедера → первый блок | 16px |
| Между секциями | 24px |
| Между карточками в списке | 8px |
| Между полями формы | 12px |
| После полей → кнопка CTA | 24px |
| Снизу до таббара | `pb-[calc(49px+env(safe-area-inset-bottom)+16px)]` |

### Фиксированные высоты

| Компонент | Высота |
|---|---|
| Кнопка Primary / CTA | 56px |
| Инпут | 56px |
| Таббар | 49px + safe-area |
| Хедер страницы | 44px |
| Пункт списка | 56–72px |
| Сегментированный контрол | 36px |
| Минимальная tap-зона | 44×44px |

### Safe-areas
Все фиксированные элементы снизу:
```html
<div class="pb-[env(safe-area-inset-bottom)]">...</div>
```
Контент под таббаром:
```html
<div class="pb-[calc(49px+env(safe-area-inset-bottom)+16px)]">...</div>
```

## 8px-чеклист для каждой платформы

**[MOB]**
- [ ] Горизонтальные поля = 16px
- [ ] Все tap-зоны ≥ 44×44px
- [ ] Safe-area учтена у фиксированных элементов
- [ ] Контент не перекрывается таббаром

**[WEB]**
- [ ] Контент не шире 1280px
- [ ] Hover-состояния у всех интерактивных элементов
- [ ] Брейкпоинты не ломают лейаут на 768–1440px

**[DSK]**
- [ ] Контент не шире 1440px, центрирован
- [ ] Sidebar фиксирован, контент скроллируется независимо
- [ ] Нет пустого пространства на 1920px (контент использует ширину)
