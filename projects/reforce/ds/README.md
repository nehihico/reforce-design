# Reforce Design System

> Единая дизайн-система для всех продуктов платформы Reforce.  
> Применяется к: **reforce-lk** (мобильное приложение), **reforce-market** (веб-магазин), будущим продуктам.

---

## Структура

```
ds/
├── README.md              ← этот файл — индекс и инструкция
│
├── ФУНДАМЕНТ
├── principles.md          ← дизайн-принципы, ценности, запреты
├── tokens.md              ← цвета, типографика, отступы, радиусы, тени, z-index
├── grid.md                ← 8px-сетка, брейкпоинты, канвас, safe areas
├── motion.md              ← анимации: длительности, кривые, типы переходов
├── copywriting.md         ← тон голоса, тексты кнопок, ошибки, статусы
├── icons.md               ← каталог иконок (Lucide), размеры, стиль, цвета
│
└── КОМПОНЕНТЫ
    ├── components-buttons.md      ← кнопки: primary, outline, ghost, icon
    ├── components-inputs.md       ← инпуты, PIN, textarea, состояния
    ├── components-cards.md        ← карточки объектов, событий, пакетов
    ├── components-navigation.md   ← таббар, хедер, степпер, пагинация
    ├── components-feedback.md     ← алерты, тосты, модалы, скелетон
    └── components-forms.md        ← чекбоксы, радио, тогглы, прогресс формы
```

## Как использовать при проектировании

### Новый экран — чеклист
1. **Принципы** → проверь соответствие 10 принципам [`principles.md`]
2. **Токены** → используй только токены из [`tokens.md`], не вводи новые цвета
3. **Сетка** → отступы кратны 8px, горизонтальный padding = 16px [`grid.md`]
4. **Компоненты** → ищи готовый компонент перед созданием нового
5. **Анимация** → переходы из [`motion.md`], не изобретай новые
6. **Тексты** → кнопки, ошибки, статусы — по правилам [`copywriting.md`]
7. **Иконки** → только из Lucide, размеры и цвета по [`icons.md`]

### Новый компонент — когда добавлять в DS
- Компонент используется в 2+ экранах → добавляй в DS
- Компонент специфичен для одного экрана → оставь в описании экрана
- При добавлении: HTML-сниппет + все состояния (default, hover, active, disabled, error)

## Продукты и специфика

| Продукт | Платформа | Особенности |
|---|---|---|
| **reforce-lk** | Flutter (iOS + Android) | Safe areas, tap 44px, нативные переходы |
| **reforce-market** | Веб (React) | Responsive, hover-состояния, SEO |
| *(будущие)* | — | Использовать те же токены и принципы |

**Приоритет по платформе:** при конфликте мобайл-специфики и веб-специфики — мобайл первичен для reforce-lk, веб для reforce-market. Токены и принципы — общие.

---

## Версионирование

DS живёт в `projects/reforce/ds/` — единственный источник правды.  
`reforce-lk/ds/` и `reforce-market/ds/` **не существуют** — продукты ссылаются на общую DS.

При изменении компонента: обновляй файл в `reforce/ds/`, не дублируй в продуктах.
