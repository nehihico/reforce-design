## Бренд-основа (стратегия → дизайн)

**Суть:** платформа, не охранная компания. Аналог — Яндекс Такси, Тинькофф.  
**Тон:** спокойная уверенная сила. Без агрессии, запугивания, технического жаргона.  
**Эталон UX:** банковские приложения РФ (Тинькофф, СберБанк).  
**Ключевой запрет:** никаких визуальных образов охраны — ни камер, ни формы, ни щитов. Только смартфон, спокойствие, контроль.

## Цветовая палитра

> Источник: лендинг v2 — «фирменные цвета: красный + тёмный». Зелёный — из описания UI «статус Под охраной».  
> **Точные HEX требуют подтверждения из Figma-файла.** Ниже — направление для согласования.

### Брендовые цвета

| Токен | Предполагаемое значение | Роль | Примечание |
|---|---|---|---|
| `--color-brand-primary` | `#D42B2B` | Фирменный красный | Подтверждён |
| `--color-brand-dark` | `#1A1A2E` | Тёмный фон / акцент | Требует подтверждения из Figma |
| `--color-brand-white` | `#FFFFFF` | Основной фон (светлая тема) | |

### Нейтральные цвета

| Токен | Значение | Использование |
|---|---|---|
| `--color-neutral-900` | `#1C1C1E` | Основной текст |
| `--color-neutral-600` | `#636366` | Вторичный текст |
| `--color-neutral-300` | `#C7C7CC` | Разделители, плейсхолдеры |
| `--color-neutral-100` | `#F2F2F7` | Фоны карточек, поверхности |
| `--color-neutral-50` | `#F9F9FB` | Фон экрана |

### Функциональные (семантические) цвета

| Токен | Значение | Смысл |
|---|---|---|
| `--color-status-armed` | `#34C759` | Объект под охраной (iOS зелёный) |
| `--color-status-disarmed` | `#8E8E93` | Снят с охраны |
| `--color-status-alarm` | `#FF3B30` | Тревога — только подтверждённая угроза |
| `--color-status-warning` | `#FF9500` | Требует внимания (задолженность, неисправность) |
| `--color-status-gbr` | `#007AFF` | ГБР направлена — информирование без паники |
| `--color-action-primary` | = `--color-brand-primary` | CTA: Поставить на охрану, Оплатить |
| `--color-action-destructive` | `#FF3B30` | Расторжение, отзыв доступа |
| `--color-action-secondary` | `#007AFF` | Вторичные действия |

**Принцип статусов:** тройное кодирование — цвет + иконка + текст. Нельзя полагаться только на цвет (WCAG AA, аудитория включает пожилых).

## Цветовая семантика (смысловые роли)

| Токен | Роль | Использование |
|---|---|---|
| `--color-status-armed` | Объект на охране | Зелёный индикатор статуса |

| `--color-action-primary` | Основное действие | CTA: Поставить на охрану, Оплатить |
| `--color-action-destructive` | Опасное действие | Расторжение, отзыв доступа |

**Принцип:** статус охраны кодируется тройным способом — цвет + иконка + текст. Нельзя полагаться только на цвет (a11y).

## Типографика

### Шрифт

| Платформа | Стек |
|---|---|
| iOS | `-apple-system, 'SF Pro Text', sans-serif` |
| Android | `'Roboto', sans-serif` |
| Веб | `-apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Roboto', sans-serif` |

### Размеры и иерархия

| Токен | Размер | Насыщенность | Line-height | Letter-spacing | Использование |
|---|---|---|---|---|---|
| `--text-display` | 28px | 700 Bold | 1.2 (34px) | -0.5px | Заголовки экранов, hero |
| `--text-title-1` | 22px | 700 Bold | 1.3 (29px) | -0.3px | Название объекта, секции |
| `--text-title-2` | 17px | 600 Semibold | 1.4 (24px) | -0.2px | Подзаголовки, навигация |
| `--text-body-1` | 15px | 400 Regular | 1.5 (22px) | 0 | Основной контент |
| `--text-body-1-med` | 15px | 500 Medium | 1.5 (22px) | 0 | Акцент в теле |
| `--text-body-2` | 13px | 400 Regular | 1.5 (20px) | 0 | Вторичная информация |
| `--text-caption` | 12px | 400 Regular | 1.4 (17px) | 0.2px | Временные метки, лейблы |
| `--text-overline` | 11px | 500 Medium | 1.4 (15px) | 0.8px uppercase | Над-заголовки секций |

**Минимум:** 12px для любого текста (аудитория включает пожилых).  
**Поддержка:** Dynamic Type (iOS), Font Scale (Android).  
**Правило:** не использовать более 3 разных размеров на одном экране.

## Отступы

> Базовая единица — 8px. Все значения кратны 8 (кроме xs=4 — исключение для микро-отступов внутри компонентов).

| Токен | Размер | Использование |
|---|---|---|
| `--spacing-2xs` | 2px | Декоративные разделители |
| `--spacing-xs` | 4px | Между иконкой и текстом, gap в чипах |
| `--spacing-sm` | 8px | Внутри компонентов, gap в группах |
| `--spacing-md` | 16px | Padding карточек, между компонентами |
| `--spacing-lg` | 24px | Между секциями |
| `--spacing-xl` | 32px | Отступы экрана (горизонтальные) |
| `--spacing-2xl` | 48px | Между крупными блоками |
| `--spacing-3xl` | 64px | Пустые состояния, hero-блоки |

## Интерактивные зоны по платформам

> [MOB] = сенсорный экран, [WEB]/[DSK] = курсор мыши.

### [MOB] Tap-зоны (обязательные минимумы)

| Элемент | Минимальный размер |
|---|---|
| Любой интерактивный элемент | 44×44px |
| Кнопка постановки/снятия | 80×80px (критичное действие) |
| Тревожная кнопка | 64×64px + защита от случайного нажатия |
| Пункт списка объектов | 56px высота |
| Элементы навигации (таббар) | 44×44px |

### [WEB] / [DSK] Hover и click-зоны

| Элемент | Минимальный размер | Hover-эффект |
|---|---|---|
| Кнопка Primary | 48px высота | `bg` темнее на 8% (`hover:bg-[#BC2525]`) |
| Кнопка Secondary | 40px высота | `bg-[#F2F2F7]` → `bg-[#E5E5EA]` |
| Пункт меню / ссылка | 32px высота | `bg-[#F2F2F7]` подсветка |
| Строка таблицы / списка | 56px высота | `bg-[#F9F9FB]` |
| Иконка-кнопка | 32×32px | `bg-[#F2F2F7]` round |
| Карточка | авто | `shadow` увеличивается, `translateY(-2px)` |

## Иконография статусов (заполнить в Figma)

- `icon-armed` — щит / замок закрытый
- `icon-disarmed` — щит открытый
- `icon-alarm` — ⚠ (только для подтверждённой угрозы)
- `icon-gbr` — машина / реагирование
- `icon-check` — галочка
- `icon-warning` — восклицательный знак

**Язык без паники:** не использовать слова «тревога», «срабатывание», «ложная тревога» в интерфейсе.
