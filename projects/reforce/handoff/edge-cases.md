# Edge Cases — Reforce

> Нетипичные состояния, которые разработчики должны реализовать.  
> Источник: PRD v3.2, UX-06, UX-07

---

## Securige недоступен

| Экран | Что показываем | Действия пользователя |
|---|---|---|
| Главная — список объектов | Последний известный статус + метка «Обновлено [время]» + баннер «Нет связи с сервером» | Потянуть для обновления |
| Объект — постановка/снятие | «Нет связи с сервером охраны. Действие сохранено и выполнится при восстановлении» | Отменить действие |
| Лента событий | Кэш последних событий + «Новые события загрузятся при восстановлении связи» | — |

**Принцип:** деградация, а не полный отказ. Критичные данные кэшируются.

---

## Offline (нет интернета)

| Ситуация | Поведение |
|---|---|
| Открытие приложения без интернета | Кэш главного экрана, статусы с меткой времени |
| Попытка поставить/снять без интернета | Постановка в очередь + уведомление «выполнится при восстановлении» |
| Тревожная кнопка без интернета | SMS-fallback на пульт (PRD: UX-07) |
| Чат без интернета | «Нет подключения» + возможность написать, сообщение отправится позже |

## Нулевые состояния (Empty States)

| Экран | Контент | CTA |
|---|---|---|
| Главная — нет объектов | Иллюстрация + «Ещё нет объектов под охраной» | «Перейти в магазин» |
| Лента событий — нет событий | «Пока всё спокойно» | — |
| Мои обращения — нет обращений | «Обращений нет» | «Написать в чат» |
| Пользователи объекта — только владелец | «Вы единственный пользователь» | «Добавить пользователя» |

## Ошибки оплаты

| Ошибка | Сообщение | Действие |
|---|---|---|
| Недостаточно средств | «Недостаточно средств на карте. Попробуйте другую карту» | Сменить карту |
| Банк отклонил | «Банк не одобрил платёж. Обратитесь в банк или попробуйте другую карту» | Повторить / Другая карта |
| Таймаут | «Оплата не прошла. Попробуйте ещё раз» | Повторить |
| Технический сбой | «Что-то пошло не так. Если деньги списались — напишите нам» | Написать в чат |

## Особые состояния аккаунта

| Состояние | Что видит пользователь | Ограничения |
|---|---|---|
| Задолженность 5 дней | Баннер «Есть задолженность» | Без ограничений |
| Задолженность 15 дней | Баннер + ограничение | Недоступно: управление доступами, магазин |
| Задолженность 30 дней | Предупреждение о снятии охраны | + Звонок менеджера |
| Задолженность 45 дней | Охрана приостановлена | Только оплата и чат |
| Договор приостановлен (FIN-05) | Баннер «Охрана приостановлена до [дата]» | Без управления охраной |
| Аккаунт неактивный (после расторжения) | Экран реактивации | Только просмотр истории и реактивация |

## Миграция (UF-05) — особые случаи

| Случай | Обработка |
|---|---|
| Телефон не найден в старом ЛК | Предложение обратиться в поддержку |
| Дубликат (один телефон, разные данные) | Экран сверки «Ваши данные — подтвердите или исправьте» |
| Пользователь без телефона в старом ЛК | Ручная миграция через поддержку |
| Частичная миграция (не все объекты) | Показать мигрированные + кнопка «Не вижу все объекты» |
