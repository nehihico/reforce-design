## 1. Ajax Security System

**Тип:** производитель оборудования + собственное приложение  
**Рынок:** глобальный (Европа, UA, СНГ, 170+ стран)  
**Рейтинг:** App Store (US) — 4.3 / 5 (258 отзывов); Google Play — 3.1 / 5 (7 400+ отзывов, 1M+ установок)  
**Платформы:** iOS 18+, Android, Wear OS, Apple Watch, Android TV, Ajax Desktop (веб)

### Онбординг и авторизация

- **Регистрация:** один аккаунт — один номер телефона. Регистрация через приложение с подтверждением email и телефона.
- **Привязка хаба:** QR-код под монтажной панелью SmartBracket → автоматическое добавление. Альтернатива — ручной ввод ID. При первом запуске предлагается пошаговый мастер настройки.
- **Онбординг при первом запуске:** при первом добавлении хаба приложение автоматически переходит к добавлению устройств (можно пропустить). Шаги: создание аккаунта → вход → Add Hub → QR-сканирование → пространства (комнаты) → добавление датчиков. Итого: 5–7 шагов до полной настройки.
- **Авторизация:** логин/пароль + подтверждение email. Поддержка Apple Watch/Wear OS для управления без телефона.

**Слабость:** нет биометрической авторизации (Face ID / Touch ID) в качестве основного метода входа — пользователи жалуются, что каждый раз приходится вводить пароль.

### Главный экран

- Устройства организованы по **комнатам и группам охраны** (зоны / партиции).
- Навигация: список пространств → внутри пространства — список устройств, разделённых по категориям.
- На главном экране отображается **общий статус** (поставлен / снят / тревога) плюс активные зоны.
- Поддерживается **Night Mode** — охрана части зон (например, периметр без внутренних датчиков).
- Кнопки постановки/снятия стилизованы под брелок: круг (постановка), C-форма (снятие), концентрические круги (ночной режим), «i» в круге (паника). Иконографика неочевидная — пользователи указывают, что иконки долго запоминаются.

### Постановка / снятие с охраны

- **1 тап** для постановки/снятия всего пространства.
- **Geofence:** автоматические напоминания при выходе/входе в заданную зону. Геозона не интегрирована с нативными картами iOS — работает через собственный движок, требует постоянного доступа к геолокации.
- Визуальный фидбек: цвет статуса + звуковое оповещение через сирену.
- Критические тревоги **пробивают режим «Не беспокоить»** — уведомление звучит на максимальной громкости.

**Слабость:** кнопки постановки/снятия скопированы с физического брелока (символы непривычны, без текстовых подписей). Виджет на домашнем экране телефона — отсутствует (критический запрос пользователей с 2023 года).

### Push-уведомления

- Контекстные: сообщают «что произошло, где и кто это сделал».
- Тревоги обходят тихий режим и режим полёта.
- **Жалобы:** нельзя настроить звук/вибрацию уведомлений — одна предустановленная схема на всех. Пользователи жалуются на «орущий телефон» от любой тревоги.
- Нет интеграции с iOS виджетами и HomeKit (запрос с 2023 года).

### Мультиобъектность

- Один аккаунт управляет **несколькими хабами/пространствами** (хабы отображаются в едином списке).
- **Videowall**: мониторинг нескольких объектов одновременно с настраиваемой сеткой камер.
- Приглашение дополнительных пользователей с разными правами (администратор, пользователь, установщик).

### Визуальный язык

- Светлая тема (основная), тёмная тема — доступна.
- Минималистичный UI, акцент на функциональность.
- Цветовые статусы: зелёный = охрана активна, красный = тревога, серый = снято.
- Иконки устройств — собственный стиль Ajax (узнаваемые, но требуют привыкания).
- Версия для Apple TV и Wear OS — единая дизайн-система.
- Низкий контраст текста в списке уведомлений: «светло-серые цифры на белом фоне — нечитаемо без увеличения» (жалоба из реального отзыва, 2024).

### Сильные стороны

- Лучший в классе по полноте функций для профессионального рынка
- Геозона, Night Mode, видеостена, Wear OS — уникальные возможности
- Быстрый QR-онбординг для установщиков
- Мультиязычность (34 языка), глобальная поддержка
- Сильный продуктовый блог и документация

### Слабые стороны / боли пользователей

- Рейтинг в Google Play заметно ниже (3.1), чем в App Store — частые крэши на Android после обновлений (66% от жалоб)
- Нет виджетов и нет HomeKit
- Кастомизация уведомлений отсутствует
- Геозона не работает с нативными картами iOS
- Apple Watch требует нахождения рядом с телефоном — не автономно
- Полная зависимость от облака (критика от пользователей, требующих offline-режим)
- Интерфейс больше ориентирован на установщика, чем на конечного пользователя

## 2. Ажур

**Тип:** российская охранная компания (ЧОО)  
**Рынок:** РФ (предположительно региональный игрок)  
**Статус данных:** компания не идентифицирована в открытых источниках под этим названием в контексте охраны. Ни App Store, ни Google Play не показывают приложение с именем "Ажур" охранной тематики. Поисковые системы (Google, Яндекс) не выдают профиль охранной компании "Ажур" с мобильным приложением или ЛК.

**Вероятные сценарии:**
1. Компания использует **белорусское наименование** (найдена "Ажур Групп" в Минске, но это автосервис).
2. Компания работает **на платформе стороннего разработчика** — например, MyAlarm (C.Nord) или Rubeg, которые используются множеством российских ЧОО под собственным брендингом.
3. Компания имеет **очень ограниченное цифровое присутствие** — характерно для региональных ЧОО.

### Что можно сказать о ЧОО, использующих платформу MyAlarm (C.Nord)

Поскольку данные по "Ажур" как отдельному игроку недоступны, и учитывая, что большинство средних российских ЧОО используют готовые платформы (MyAlarm, Rubeg38, Болид), ниже — анализ MyAlarm как наиболее распространённой платформы для ЛК в сегменте.

**Онбординг:** вход по номеру телефона + SMS-код (без пароля). Поддержка Face ID / Touch ID. 3–4 шага до первого использования.

**Главный экран:** объекты в виде иконок с цветовым индикатором (поставлен/снят/тревога). Красный колокольчик — при активной тревоге. Все объекты — в одном приложении.

**Постановка/снятие:** 1–2 тапа + ввод кода (пользовательский PIN для подтверждения действия).

**Push-уведомления:** настраиваемые по объекту, голосовой ассистент «Рита» озвучивает события без разблокировки телефона.

**Мультиобъектность:** все объекты в едином списке, управление секциями раздельно.

**Слабости платформы:** нет кастомизации интерфейса, дизайн утилитарный, нет темной темы, видеонаблюдение — опционально.

### Итог по разделу

Публично верифицированных данных о мобильном приложении или личном кабинете компании "Ажур" (охрана, РФ) найти не удалось. Раздел включён как аналитическая заглушка. Перед итоговым решением рекомендуется запросить прямой доступ к приложению или скриншоты через команду исследований.

## 3. Сфера безопасности

**Тип:** российская охранная компания (ЧОО, Челябинск)  
**Сайт:** sfera174.ru, sbural174.ru  
**Рынок:** Урал, Челябинская область  
**Статус приложения:** собственное мобильное приложение не идентифицировано в публичных магазинах под брендом «Сфера безопасности Челябинск». Возможно использование платформы Rubeg или MyAlarm.  
**Рейтинг на ПроЧОП:** 4.5/5 (8 отзывов — выборка мала)

### Что известно из открытых источников

**Основной акцент компании:** физическая охрана предприятий, тревожная кнопка, видеонаблюдение. Мобильное приложение упоминается в единственном пользовательском кейсе: «контролирую происходящее на объекте с помощью мобильного приложения».

**Онбординг:** данных нет. По характеру продукта — вероятно, через представителя компании (не самостоятельная регистрация).

**Главный экран:** данных нет.

**Постановка/снятие:** данных нет.

**Push-уведомления:** данных нет.

**Мультиобъектность:** данных нет.

**Отзывы пользователей:** немногочисленны, касаются качества физической охраны и скорости реакции, а не цифрового продукта. Компания оценивается положительно как сервисная, но цифровой канал не является конкурентным преимуществом.

**Визуальный язык:** сайт sfera174.ru — минималистичный корпоративный стиль, синяя гамма. Мобильное приложение не представлено на сайте.

### Итог по разделу

"Сфера безопасности" — региональный игрок без выраженного цифрового продукта. Публичных данных о мобильном приложении, его UX или рейтинге в магазинах недостаточно для полноценного анализа. Компания является референсом для понимания нижней границы рынка: клиент получает охрану «по звонку», а не через самообслуживание в приложении.

## 4. Дельта / GoDELTA

**Тип:** федеральная охранная компания (DELTA Системы безопасности)  
**Сайт:** delta.ru  
**Рынок:** РФ (Москва, Уфа, Екатеринбург, Тольятти, Воронеж, Сочи и др.)  
**Приложение:** GoDELTA (iOS App Store: 1.5/5, ~1700 отзывов; Google Play: аналогичные проблемы)  
**Разработчик приложения:** ALBERT SOFT (переработка — L-TECH, 5 месяцев, команда 10 человек)  
**Номинации:** RUWARD AWARD 2023 в категории мобильных приложений

### Онбординг и авторизация

- Авторизация: логин/пароль (традиционная схема, без SMS-первичного входа).
- Первичное подключение — через офис/менеджера компании, самостоятельная регистрация не заявлена.
- Онбординг внутри приложения: кастомизация главного экрана при первом запуске (выбор типа навигации — кнопки или свайп, выбор темы).
- Количество шагов до первого использования: 3–5 (авторизация → персонализация → главный экран).

### Главный экран

- **Полная кастомизация главного экрана** — ключевая дифференциация. Пользователь сам выбирает, какие виджеты отображаются.
- Объекты представлены в виде карточек с возможностью загрузки собственного фото и переименования.
- Переключение между объектами: список карточек (ориентация на 1–3 объекта).
- Навигация: два варианта — кнопочная или свайп-жесты. Пользователь выбирает при настройке.
- Тёмная и светлая тема.

### Постановка / снятие с охраны

- Кнопка постановки/снятия — на главном экране карточки объекта.
- Два варианта взаимодействия: тап или свайп (пользователь выбирает).
- Панику (тревожная кнопка) — отдельная кнопка.
- Виджет на домашнем экране смартфона добавлен в версии 4.12.0.
- **Проблема (2025–2026):** с января 2026 года приложение работает с критическими сбоями, постановка/снятие удалённо — нестабильны. Компания обещала исправить в 2–3 дня, проблема не решена на протяжении нескольких месяцев.

### Push-уведомления

- Бесплатные push-уведомления.
- Фильтрация событий по объекту и периоду.
- История событий с фильтрацией.
- **Жалобы:** красные бейджи непрочитанных уведомлений не сбрасываются после прочтения — постоянный раздражитель интерфейса.

### Мультиобъектность

- Несколько объектов в одном приложении.
- Список объектов + управление доверенными лицами (кому разрешён доступ к объекту).
- Управление правами: пользователь может давать другим право просматривать статус и управлять постановкой/снятием.

### Визуальный язык

- Современный, адаптивный. Корпоративный синий/серый — основная палитра.
- Светлая и тёмная тема.
- Кастомные фото объектов в карточках.
- Видеонаблюдение: отдельный раздел с поддержкой облачного и локального архива, онлайн-просмотром.
- Дизайн переработан в 2023 году (кейс L-TECH).

### Сильные стороны

- Лучшая в сегменте кастомизация главного экрана (выбор лейаута, жеста, темы, фото)
- Виджет на домашнем экране
- Фильтрация событий по периоду
- Управление доверенными лицами
- Поддержка СБП (Система быстрых платежей)
- Наличие профессионального UX-кейса (RUWARD AWARD 2023)

### Слабые стороны / боли пользователей

- Рейтинг App Store: **1.5/5** — критически низкий. Приложение фактически сломано с января 2026 (к моменту анализа)
- Поддержка медленная, отвечает общими фразами, не устраняет проблему месяцами
- Бейдж уведомлений не сбрасывается — постоянный UI-баг
- Нет самостоятельной онлайн-регистрации — требует обращения в офис
- Дизайн современный, но надёжность сервиса разрушает весь UX

## 5. Гольфстрим

**Тип:** российская охранная компания (Гольфстрим охранные системы, АО)  
**Сайт:** gulfstream.ru (также через МТС — москва.мтс.ру)  
**Рынок:** Москва и МО (крупный игрок, дочерняя структура МТС)  
**Приложение:** "Гольфстрим" (iOS App Store: **4.6/5**, 15 000+ отзывов; Google Play: 4.6/5, 5220 отзывов)  
**Важно:** приложение доступно **только абонентам** Гольфстрим — не публичное

### Онбординг и авторизация

- Доступ только после заключения договора с компанией.
- Авторизация: логин/пароль (вход через аккаунт абонента).
- **Жалобы:** приложение часто не запоминает авторизацию и просит повторно вводить логин/пароль — раздражающий баг для постоянных пользователей.
- Нет публичных данных о биометрической авторизации.

### Главный экран

- Статус объекта (поставлен / снят / тревога) — на переднем плане.
- Быстрый доступ к основным функциям: постановка/снятие, SOS-кнопка, видео, оплата.
- Управление умным домом: свет, розетки, бойлер, температура.
- История событий и история кто ставил/снимал — в ЛК (информативно, по отзывам).

### Постановка / снятие с охраны

- **Одно касание** для постановки/снятия.
- Дополнительные способы: брелок, электронный ключ, пульт, браслет (интеграция физических и цифровых способов).
- Красная кнопка SOS — вызов экипажа без ожидания срабатывания датчика.
- Визуальный фидбек: не описан детально в доступных источниках.
- **Геозона:** отсутствует. Пользователи указывают: «Очень не хватает автоматической постановки/снятия по геолокации» (iOS Shortcuts не поддерживаются).

### Push-уведомления

- Мгновенные push-уведомления по событиям.
- **Фото по тревоге:** уведомления включают снимок с камеры (фотоверификация).
- Проактивные уведомления о замене батареек, отключении питания, статусе системы.
- 7-дневное облачное хранение видео по событиям.
- Тон: информативный, нейтральный.

### Мультиобъектность

- Несколько объектов в одном приложении (стандартная функция).
- Настройка приоритетов вызова при тревоге (кому звонить первому).
- Добавление дополнительных пользователей.
- Данных о специальном UX для переключения между объектами нет.

### Визуальный язык

- Размер приложения: 188 МБ (крупное).
- Язык интерфейса: только русский.
- Возрастной рейтинг: 16+ (из-за сбора финансовых данных и геолокации).
- Стиль: корпоративный, доверительный. Предположительно тёмно-синяя гамма (фирменные цвета Гольфстрим — синий и белый).
- Сбор данных: финансовая информация, точная геолокация, контакты, фото/видео.

### Сильные стороны

- Лучший рейтинг в сегменте: **4.6/5 при 15 000+ отзывов** — серьёзная выборка, не случайность
- Фото-верификация тревог прямо в push-уведомлении
- Интеграция с умным домом (свет, температура, розетки)
- Многоканальность управления (приложение + брелок + электронный ключ + браслет)
- Информативный ЛК: история событий, кто и когда ставил/снимал
- Оплата без комиссий, автоплатёж

### Слабые стороны / боли пользователей

- Периодические сбросы авторизации — приложение не запоминает пользователя
- Нет геозоны (автоматической постановки/снятия по местоположению)
- Только русский язык
- Отдельные случаи: приложение не работало 6 месяцев без реакции поддержки
- Двойное списание через автоплатёж (единичные, но финансово болезненные случаи)
- Время прибытия ГБР: отдельные жалобы на 25-минутное ожидание

## 7. Выводы для Reforce

### Что взять (лучшие практики)

**1. Авторизация — по номеру телефона + SMS** *(платформа MyAlarm, частично Гольфстрим)*  
Российский рынок: пользователи привыкли к входу через телефон. Убирает барьер «забытый пароль». Добавить Face ID / Touch ID — ни один из конкурентов не реализовал полноценно; это быстрая победа для Reforce.

**2. Фото-верификация в push-уведомлениях** *(Гольфстрим)*  
Главная боль пользователя при тревоге — не знаешь, ложная она или нет. Фото прямо в пуше снимает тревожность и снижает число лишних звонков в ГБР. Reforce должен реализовать это с первого дня.

**3. Постановка/снятие = 1 тап, но с понятными иконками** *(урок от Ajax)*  
Ajax ошибся: скопировал иконографику брелока (символы без слов). Reforce должен использовать текстовые подписи + понятные иконки. Главное действие — самое крупное на экране, без скролла.

**4. Виджет на домашнем экране** *(GoDELTA, запрос у Ajax)*  
Постановка/снятие через виджет — top-requested feature на всех платформах. GoDELTA добавил в v4.12. Reforce должен заложить с релиза.

**5. История событий с временными метками и авторством** *(Гольфстрим, GoDELTA)*  
«Кто и когда ставил/снимал» — высоко ценимая функция. Особенно для B2B и семейного использования (дача, офис).

**6. Кастомизация главного экрана** *(GoDELTA — лучший в классе)*  
Возможность выбрать тип навигации (свайп/кнопки), тему (светлая/тёмная), загрузить фото объекта и переименовать его — делает приложение «своим». Реализуемо постепенно, но темы (светлая/тёмная) — обязательны с v1.

**7. Онбординг через QR-сканирование** *(Ajax)*  
Для сегмента, где клиент подключает оборудование: QR-код снижает ошибки при вводе ID вручную. Для Reforce — применимо при привязке охранного объекта к аккаунту.

**8. Мгновенные push и пробивание «Не беспокоить»** *(Ajax, Гольфстрим)*  
Тревожные уведомления должны достигать пользователя всегда. Это не UX-улучшение, это требование безопасности. Реализовать через APNs Critical Alerts (iOS) и Notification Channels HIGH_PRIORITY (Android).

**9. Автоматическая постановка/снятие по геозоне** *(Ajax — базовая реализация)*  
Ни один российский конкурент не реализовал это полноценно. Ajax сделал, но плохо (не через нативные карты). У Reforce есть возможность занять нишу с нормальной геозоной через интеграцию с CoreLocation / Google Maps API.

**10. Интуитивная мультиобъектность** *(Ajax, GoDELTA, Гольфстрим)*  
Переключение между объектами должно быть < 2 тапов. Карточная модель с фото объекта — понятный паттерн. Для Reforce, учитывая приоритет B2C + SMB, мультиобъект важен с версии 1.

---

### Чего избежать (антипаттерны)

**1. Иконки без текстовых подписей для постановки/снятия** *(Ajax)*  
Абстрактные символы (круг, C-форма) требуют обучения. Пользователи путаются. Для аудитории Reforce, включающей пожилых людей, это критично.

**2. Несбрасываемые бейджи уведомлений** *(GoDELTA)*  
Классический UI-баг, который раздражает ежедневно. Баг простой в исправлении, но показывает небрежность в QA.

**3. Запуск приложения без резервных каналов** *(GoDELTA 2026)*  
Полная зависимость от одного канала (интернет-соединение + облако) без fallback-механизма привела к тому, что тысячи объектов остались без охраны на месяцы. Reforce должен иметь offline-индикацию статуса и SMS-канал как резерв.

**4. Отсутствие биометрической авторизации** *(все конкуренты)*  
Ни один из пяти конкурентов не реализовал Face ID / Touch ID как основной метод входа. Это значимый UX-разрыв, который Reforce может закрыть с первого релиза.

**5. Только русский язык без локализации** *(Гольфстрим, GoDELTA)*  
Ограничивает масштабирование. Ajax — мировой лидер в том числе потому, что поддерживает 34 языка. Reforce — стартует с RU, но архитектура l10n должна быть заложена сразу.

**6. Сложный онбординг через офис** *(Дельта, Гольфстрим, Сфера)*  
Требование прийти в офис для первичного подключения — порог входа, несовместимый с digital-first аудиторией. Reforce должен обеспечить 100% самостоятельный онбординг онлайн.

**7. Отсутствие кастомизации уведомлений** *(все конкуренты)*  
Один пресет звука/вибрации для всех событий — как тревога, так и штатное снятие. Пользователи хотят разные профили. Простое решение: 3 категории (критическая тревога / важное событие / информационное) с разными звуками.

**8. Интерфейс, скопированный с физических устройств** *(Ajax)*  
Брелочные символы в мобильном интерфейсе — это перенос физической метафоры в digital без переосмысления. Reforce должен проектировать UI для пальца, а не для кнопки на брелоке.
