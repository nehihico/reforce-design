## Definition of Done по модулям (из PRD 12.5)

### AUTH
- [ ] Успешная авторизация >95% на выборке 1000 пользователей
- [ ] Время предоставления доступа <5 мин
- [ ] Миграция >95% существующих пользователей без обращений

### SEC (управление охраной)
- [ ] Постановка/снятие ≤2 сек от нажатия до подтверждения (p95)
- [ ] Статус обновляется в реальном времени (<3 сек задержка)
- [ ] Лента событий отображает все типы с корректной атрибуцией

### PUSH
- [ ] Доставляемость ≥98% на выборке 10 000 уведомлений
- [ ] Токены не протухают в течение 90 дней без активности
- [ ] SMS-fallback срабатывает при недоставке за 60 сек

### SUP (чат)
- [ ] 100 одновременных пользователей без деградации
- [ ] Uptime ≥99.9% за 7 дней
- [ ] Оператор видит контекст клиента
