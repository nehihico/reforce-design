# Directive: Построение персон

## Когда использовать
После брифа, до проектирования IA. Персоны строятся на основе данных из PRD и исследований.

## Процесс

1. Прочитай `projects/{slug}/brief.md` и `projects/{slug}/prd.md`
2. Выдели сегменты пользователей из PRD (раздел «Целевые пользователи»)
3. Для каждого сегмента заполни шаблон из `templates/persona.md`
4. Проверь: покрывают ли персоны все ключевые user flows из PRD?

## Структура персоны

- **Имя и фото-описание:** архетипичный образ (не реальный человек)
- **Роль в системе:** какая роль в ролевой модели продукта
- **Контекст использования:** когда, где, на каком устройстве
- **Ключевая задача (Job):** главное что хочет сделать
- **Боли:** что мешает сейчас
- **Страхи:** чего избегает, что вызывает тревогу
- **Ожидания от продукта:** что считает «нормальным» сервисом
- **Технический уровень:** насколько уверен с приложениями
- **Частота использования:** как часто открывает приложение

## Для продукта Reforce — обязательные персоны

Из PRD выделено 3 сегмента:
1. Владелец недвижимости (физ. лицо, 1-2 объекта)
2. Малый бизнес (ИП/ООО, 2-3 объекта)
3. Сетевой бизнес (администратор компании, 10-100+ объектов)

Дополнительно: каждая роль в ролевой модели (наблюдатель, пользователь охраны, ответственное лицо).
