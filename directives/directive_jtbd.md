# Directive: Jobs To Be Done

## Когда использовать
После персон, перед построением IA. JTBD — это ситуации и мотивации, не описание пользователя.

## Формат JTBD

```
Когда [ситуация],
я хочу [мотивация / действие],
чтобы [ожидаемый результат].
```

## Процесс

1. Прочитай `personas.md` — выдели ключевые ситуации для каждой персоны
2. Прочитай `prd.md` — раздел User Flows — это готовые источники для JTBD
3. Для каждого JTBD оцени приоритет: Critical / High / Medium / Low
4. Сгруппируй по функциональным областям (охрана, финансы, поддержка и т.д.)
5. Убедись, что каждый Must-have из PRD покрыт хотя бы одним JTBD

## Ловушки

- JTBD — это не фича. «Хочу видеть статус объекта» — плохо. «Когда я уезжаю из офиса, хочу быстро убедиться что всё поставлено на охрану» — хорошо.
- Не смешивай функциональные и эмоциональные jobs в одном пункте
- Один JTBD = одна ситуация, не список

## Связи

- JTBD → User Flows (`ia/user-flows.md`)
- JTBD → Приоритизация экранов (`ia/sitemap.md`)
