# Directive: Accessibility-аудит (a11y)

## Контекст для Reforce
Целевая аудитория включает пожилых людей. Требования из PRD: tap-зоны ≥ 44px, высокая контрастность.

## Чеклист

### Размеры и отступы
- [ ] Tap-зоны всех кнопок и ссылок ≥ 44×44px
- [ ] Отступы между интерактивными элементами ≥ 8px
- [ ] Критичные кнопки (тревожная, постановка/снятие) ≥ 60px

### Цвет и контрастность
- [ ] Текст на фоне: соотношение ≥ 4.5:1 (WCAG AA)
- [ ] Крупный текст (≥ 18px): соотношение ≥ 3:1
- [ ] Информация не передаётся только цветом (статус охраны = цвет + иконка + текст)

### Типографика
- [ ] Минимальный размер текста ≥ 14px
- [ ] Поддержка Dynamic Type (iOS) и Font Scale (Android)
- [ ] Лейблы полей ввода всегда видны (не исчезают при вводе)

### Статусы и состояния
- [ ] Статус охраны: цвет + иконка + текстовая метка (тройное кодирование)
- [ ] Уведомления об ошибках: не только красный цвет
- [ ] Критичные уведомления доступны через VoiceOver / TalkBack

### Язык и текст
- [ ] Нет технических терминов (шлейф, пинкод, зона охраны → понятные аналоги)
- [ ] CTA-кнопки: глагол + объект («Поставить на охрану», не «Армировать»)
- [ ] Сообщения об ошибках объясняют что делать дальше
